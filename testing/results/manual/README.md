# Manual results

`python testing/solo_test.py --name YOU` saves each run here as
`YOU_<script>_<date>_<time>.txt` (the recording is saved next to it as a `.wav`,
which git ignores, so your voice stays on your computer).

Push the `.txt`, or send it to Claude, and add a row to the
[manual runs table](../../testing.md#manual-runs-by-the-team).
